# 1.1.0 发布说明

Android 8.0+，版本 1.1.0 / versionCode 44，正式包名 `com.yuejian.app`。数据库 schema 11，备份格式 4。

## 使用

从 Releases 下载 APK 安装。已有作者签名正式版可以覆盖升级；Debug 包与正式包不同，迁移使用应用内备份恢复。API Key 需要自己配置，圈图需支持图片的模型。

本版新增跨页补充资料与同一个问答窗口，压缩保留最近 4 轮完整问答。详细流程见 README 和 [harness.md](harness.md)。

## 验证边界

该正式包此前完成 Release APK / AAB 构建与 APK 签名验证。本次发布整理运行模型、接口、排版的单元测试任务成功，共 53 项测试结果无失败；5 项 DAO SQL / 迁移检查通过。设备测试 APK 已编译，不等于已在设备上运行。

触控、覆盖升级、真实模型调用与设备备份恢复仍需要用户验收。GitHub Actions 是后续构建检查入口，不把首次未运行的 CI 写成已通过。

## 快速验收

导入 PDF → 文字问答 → 圈图问答 → 跨页补充 → 点不同关联标记返回同一问答 → 保存卡片 → 重开资料 → 备份恢复。检查黑白主题、手机窄屏、停止 / 重试和缺少图片能力时的提示。

安装包和宣传视频作为 Release 附件，不进入源码历史。发布私钥、本机凭据、SDK、临时文件及用户资料不进入仓库。
