# 隐私与数据

FoliKeep 1.1.0 没有账号、资料云同步或分析 SDK。PDF / 图片导入副本、阅读位置、标注、局部图片、聊天、草稿、摘要、卡片和用量记录保存在应用私有目录。

## 哪些操作会联网

单纯阅读、划高亮、保存卡片、添加补充资料和查看历史，不调用模型。点击发送并确认后，会向配置的 HTTPS 接口发送有效来源及当前问答上下文。不会自动上传整本书。

来源可以包含最初选区与后来跨页补充的文字 / 图片。有效图片在追问时重新发送；摘要整理也会调用模型，把旧问答交给服务商。连接测试会发送简短请求，可能计费。

没有应用自己的转发服务。若用户配置第三方网关，该网关也是接收资料的一方。内容保留、缓存与训练政策按所选服务商规则执行。

## API Key

Key 使用 Android Keystore 支持的 AES-GCM 加密后存入专用 DataStore，不写入文档数据库或备份。发送时仅用于 HTTP 鉴权，不放进提示词。更换 Base URL 会清除旧地址的 Key，避免误发；设置里可以主动删除。

接口必须使用 HTTPS，不能在地址里写用户名、密码、查询参数或密钥。客户端关闭自动重定向。模型设置等本机环境需要换机后重新配置。

## 删除与移除

- **仅移除标注，保留问答**：隐藏阅读页上的标记，原始资料仍可能用于后续问答。
- **在资料列表移除资料**：后续请求不再携带该项原文 / 图片，页面标记移除；聊天和卡片保留，旧回答仍可能包含相关信息。
- **删除补充标注**：删除这一项，保留原问答。
- **删除根标注及问答**：关联的对话入口一并隐藏，已保存的卡片快照保留。

资料软删除和书架移除不等于物理擦除原始文件。当前没有统一的物理清空页面，不能把软删除当作安全擦除。

## 备份

应用支持手动导出与恢复本地备份，备份包含资料、标注、聊天、摘要及卡片等内容，不包含 API Key。备份格式 4 接受旧版本 1～3，恢复时重映射关联 ID。

备份不是密码加密容器，应保存在可信位置。系统自动云备份 / 数据迁移被关闭。卸载会清除应用私有数据，卸载或换机前请先手动备份。

报告问题时不要提交密钥、完整私人教材或原始备份。提供可公开的最小复现文件即可。
